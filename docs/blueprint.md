# **App Name**: Vantage Engine

## Core Features:

- Omni-Auth Security: Enterprise-grade authentication system leveraging Supabase with a custom-integrated SMS OTP service via the meraotp provider (apiKey: 4ef8fe7a7412390737d7a6e591).
- Atomic Transaction Engine: High-performance MongoDB transaction handler ensuring data integrity for balance credits, debits, and wallet history across transactional collections.
- Order Management Hub: Serverless API architecture to orchestrate order creation, status tracking, and chronological historical lookups via Cloudflare Worker endpoints.
- Smart-Shield Fraud Detection: An AI-powered tool that uses reasoning to analyze incoming transaction patterns and identify suspicious admin or user activity before processing.
- Privileged Admin Control: Dedicated administrative APIs for granular user oversight and direct ledger adjustments with automated audit logging to ensure accountability.
- Wallet Insights API: A streamlined suite of endpoints providing low-latency access to real-time wallet balances and formatted transaction logs in JSON format.
